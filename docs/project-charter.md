# Project Overview
Expense Tracker is a web application that enables people to record expenses, monitor financial activity, record income, and gain insights into their spending habits to support better financial decision-making. 

## Problem Statement
Many individuals record their income and expenses inconsistently or not at all, making it difficult to understand spending habits, monitor financial health, and plan future budgets.

## Business Objectives
The project aims to build these features to improve financial tracking:

1. Improve visibility into monthly spending.
2. Help users make informed financial decisions.
3. Enable users to record income and expenses.
4. Categorize expenses to visualize spending.

## Scope

### In Scope
The following features are included in Version 1:
- Dashboard
- Authentication
- Income management
- Expense management
- Category management
- Reports

### Out of scope
The following features are outside the scope in Version 1:
- Bank integration
- Mobile application
- Shared accounts
- Investments

## Assumptions
- Users will have internet access.
- Users will manually enter their transactions.
- Users will own only one personal account.

## Constraints
- Free hosting providers
- Limited time and budget
- Personal portfolio project

## Risks
| Risk | Mitigation |
| ---- | ---------- |
|Scope grows too quickly| Prioritize minimum viable product|
| Free hosting limits | Monitor hosting resource usage and optimize deployment configuration.
| Security issues | Follow Laravel and React security best practices


## Success Criteria
The criteria is set to put goals into completion.
- Users and register and log in.
- Users can manage income and expenses.
- Application is publicly accessible and functional through production deployment.
- Project documentation allows another developer to set up the application using the README.
