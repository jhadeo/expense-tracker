# User Stories

## Authentication

| Code | As a... | I want to... | So that...|
|-|-|-|-|
US-001 | Guest | Register an account | I can securely manage my finances.|
US-002 | Guest | Log in my account | I can access my financial records.| 
US-003 | Guest | Reset my password | I can regain access if I forget it.|
US-004 | Registered User | Log out of my account | My account remains secure on shared devices. |
US-005 | Registered User | View my profile | I can verify my account details |
